# GIkku-AI-Assistance

Gikku is a Python-based personal voice assistant that allows users to interact with their computer using voice commands. It listens through the microphone, recognizes spoken instructions, and responds aloud using text-to-speech.

The project demonstrates how Python can be used to build a simple voice-controlled assistant with speech recognition, audio processing, and browser automation.

✨ Features

Voice Recognition: Listens to spoken commands through the microphone.

Voice Responses: Responds aloud using text-to-speech.

Time and Date: Announces the current time and date.

Website Automation: Opens Google, YouTube, and GitHub using voice commands.

Command Handling: Processes supported commands and provides responses.

Error Handling: Handles unclear speech, microphone timeouts, and speech recognition connectivity issues.

Interactive Experience: Continuously listens for commands until the user asks it to stop.

🛠️ Technologies Used

Python

SpeechRecognition – Converts spoken commands into text.

PyAudio – Captures microphone input.

pyttsx3 – Converts text responses into speech.

Webbrowser – Opens websites through the default browser.

Datetime – Retrieves the current date and time.
